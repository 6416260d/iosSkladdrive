# Курьер для iPhone

Проект открывается в Xcode 26 или новее. Приложение использует действующий кабинет водителя выбранного города. Для входа подходят логин и пароль сотрудника или вход через Telegram.

## Запуск

1. Откройте `Courier.xcodeproj` на Mac и выберите схему Courier.
2. Для проверки выберите симулятор iPhone и нажмите Run. Для установки на свой iPhone выберите телефон и свою команду в Signing & Capabilities.
3. Выберите город и войдите как водитель. Для проверки без рабочих заказов в списке есть демо. Разрешение на геопозицию потребуется, чтобы отмечать доставку по адресу и передавать координаты во время смены.

На устройстве проверьте передачу геопозиции при заблокированном экране, открытие Яндекс Навигатора и выход из аккаунта. Список городов хранится в `Courier/servers.json`.

## TestFlight

На Mac выберите устройство для iOS, укажите команду Apple Developer и выполните Product → Archive → Distribute App → App Store Connect. В App Store Connect нужна карточка приложения с идентификатором `ru.mise.courier`. Для следующей загрузки увеличьте Build в настройках проекта.

В GitHub Actions отправка в main запускает сборку для симулятора. Для загрузки в TestFlight настройте секреты APPLE_TEAM_ID, ASC_KEY_ID, ASC_ISSUER_ID и ASC_KEY_P8, затем запустите TestFlight вручную с параметром upload. У ключа должны быть права на приложение и автоматическую подпись. Если команда ограничивает управление сертификатами, архив можно подписать в Xcode на Mac с настроенной учётной записью.

После одобрения внешнего тестирования добавьте сборку в группу водителей и включите публичную ссылку. Чтобы кнопка установки появилась в кабинете на iPhone, сохраните эту ссылку в поле `testflight` файла `web/app/ios.json` на сервере склада.
